# Tabac Mauritanie Express

Plateforme de commande pour boutiquiers (PWA, Supabase, GitHub Pages).

## Lancer / tester
Ouvrir le site publié sur GitHub Pages (depot tabac-express).

## Fichiers principaux
- index.html : accueil
- catalogue.html : catalogue et panier
- commandes.html : historique des commandes
- connexion.html : inscription / connexion
- admin.html : espace administrateur (role admin requis)
- style-tme.css : styles

## Base de donnees
Supabase (tables produits et commandes, RLS activee).
La cle publique et l'URL Supabase sont dans les pages HTML.

## Deploiement
git add -A, git commit, git push (GitHub Pages).
